# Declarations

The submission requirements (EESE BEng Final Report 2025-26) include
an ethics questionnaire, a risk assessment and a Generative AI usage
appendix. All three are bound INSIDE the report PDF as appendices:

- **Ethics questionnaire** — Appendix B of the report
  (`FYP_Report_..._Final_checkpoint_v2.docx`), including the screenshot
  of the completed School-of-Engineering ethics screening form.

- **Risk assessment** — Appendix C of the report.

- **Generative AI usage** — Appendix D of the report, including the
  table of tools used (Table D.1) and a brief description of how each
  was used during the writing process.

This subfolder is therefore an intentionally empty pointer; the
declarations are submitted as part of the graded report PDF rather
than in this supporting-files package.
