  ────────────────────────────────────────────────────────────────────────
  Caption: Three-stage meta-kinematics pipeline. Stage 1 trains one
  single-task ResMLP per DoF on its own dataset. The three Stage-1
  checkpoints are averaged to warm-start a shared ResMLP_Mask in Stage 2,
  trained jointly on the union of all three datasets. The Stage-2 shared
  checkpoint is then fine-tuned on each DoF's support set in Stage 3,
  producing a deployable per-DoF model in 0.111-0.365 hr (vs 1.873-22.12
  hr for the single-task baselines).

  Stage-1 backbone is the same residual-block stack but WITHOUT the
  mask_proj branch (Stage-1 ResMLP takes only q as input). The Stage-1
  ResBlock has identical layers to the Stage-2/3 ResBlock but does NOT
  apply Dropout in its forward pass, so its forward is:
      x → fc1 → ReLU → fc2 → +skip → ReLU
